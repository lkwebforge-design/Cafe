# Iced Latte — Café Website

A responsive, warm-toned café landing page inspired by the uploaded Canva iced-latte video.

## Add the hero video

The hero is configured to use this file path:

`assets/iced-latte.mp4`

1. Open the repository on GitHub and choose **Add file → Upload files**.
2. Create or select the `assets` folder and upload the Canva MP4.
3. Rename the file exactly to `iced-latte.mp4`.
4. Commit the upload to `main`.

The video is configured for muted autoplay, looping, and inline playback. It pauses when the hero is outside the viewport and resumes when it comes back into view. Some browsers may block autoplay if the video is not muted.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Once the Pages deployment finishes, GitHub will show the public website URL in that settings panel.

## Notes

- Static HTML/CSS/JavaScript; no build step required.
- Mobile navigation and reduced-motion preferences are supported.
- Replace the sample menu, contact email, and location details with the café's real information before using this as a client-facing site.
